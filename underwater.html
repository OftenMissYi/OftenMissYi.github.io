Underwater Robot
Control System

Design and implementation of an embedded control and electrical system for an underwater robot, integrating real-time control, sensor feedback, communication, and autonomous navigation.

Project Overview

Development of the electrical and embedded control system for a small underwater robot, covering system architecture, hardware integration, real-time control, sensor feedback, and motion control.

System Architecture

The control system uses a hierarchical architecture connecting the operator interface, onboard computing, embedded control, sensors, and underwater actuators.

Control System Architecture

Hierarchical architecture connecting the upper-level computer, STM32-based MCU control unit, sensors, and actuators. User commands are processed by the onboard computer and translated into low-level control signals, while sensor and camera data are returned to the operator.

Electrical System Design

Design and integration of the onboard electrical system within the constrained cylindrical enclosure, with emphasis on modularity, maintainability, thermal management, and system integration.

Parametric Electrical Equipment Model

Parametric layout of the internal electrical equipment, providing a modular basis for component positioning, installation, and system integration.

Electrical Equipment Installation

Installation arrangement of the onboard electrical components within the sealed enclosure, designed to maintain structural clearance and facilitate maintenance.

Physical Electrical Equipment Layout

Final physical arrangement of the electrical equipment, with the main electronics concentrated around the central support structure to improve integration, weight balance, and internal accessibility.

Embedded Control

The embedded control system was implemented around an STM32-based MCU control unit and an NVIDIA Jetson Xavier NX onboard computer. The Xavier handles higher-level command processing and communication, while the MCU performs real-time actuator control.

The control software uses FreeRTOS to organize real-time tasks including sensor acquisition, communication, control computation, and actuator output.

User commands are processed through ROS on the Xavier and transmitted to the MCU through serial communication. The MCU converts the commands into PWM signals for the underwater thrusters, servo actuator, and lighting system.

Sensor & Actuator Integration

The embedded system integrates a USB camera and an MS5837 depth sensor for visual feedback and underwater depth measurement. Depth data is acquired by the MCU and used as feedback for motion control.

The actuator system consists of four underwater thrusters, a servo-driven gripper, and an underwater light. The MCU generates the corresponding control signals according to commands received from the onboard computer.

This architecture separates high-level computation from deterministic low-level control, allowing perception, command processing, and real-time actuator control to operate as coordinated subsystems.

Motion Control & Navigation

A mathematical model of the underwater robot was developed to describe its translational and rotational motion under the forces and moments generated by the four thrusters.

The motion-control pipeline consists of position control, attitude control, control allocation, and motor control. The calculated motion commands are converted into individual thruster commands and transmitted to the embedded controller.

ROS-based control and perception were integrated with the embedded system to support visual tracking and higher-level navigation. A* and D* path-planning methods were also incorporated for autonomous navigation.
