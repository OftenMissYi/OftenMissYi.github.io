Underwater Robot

Design and implementation of an embedded control and electrical system for an underwater robot, integrating real-time control, sensor feedback, communication, and autonomous navigation.

Overview

Embedded Control & Electrical System

This project focused on the design and implementation of the electrical and embedded control system for a small underwater robot.

The work covered system architecture, embedded real-time control, sensor integration, communication, actuator control and autonomous navigation.

Objective

System Requirements

  • Establish communication between the underwater robot and the operator.
  • Implement embedded motion and actuator control.
  • Integrate visual and depth sensing for feedback.
  • Control the thrusters, gripper servo and underwater lighting.
  • Support stable operation through an integrated power architecture.
  • Enable visual tracking and autonomous path planning.
System Design

Control System Architecture

The control system adopts a hierarchical architecture connecting the operator interface, onboard computer, embedded MCU controller, sensors and underwater actuators.

Embedded Control

Real-Time Control System

The embedded control system was implemented around an STM32-based MCU controller and an NVIDIA Jetson Xavier NX onboard computer. The Xavier performs higher-level command processing and communication, while the MCU handles deterministic real-time actuator control.

FreeRTOS organizes real-time tasks including sensor acquisition, communication, control computation and actuator output.

Commands are processed through ROS on the Xavier and transmitted to the MCU through serial communication. The MCU converts these commands into PWM signals for the underwater thrusters, servo actuator and lighting system.

Sensor & Actuator Integration

Perception & Actuation

The embedded system integrates a USB camera and an MS5837 depth sensor for visual feedback and underwater depth measurement.

The actuator system consists of four underwater thrusters, a servo-driven gripper and an underwater light. The MCU generates the corresponding control signals according to commands received from the onboard computer.

This architecture separates high-level computation from deterministic low-level control, allowing perception, command processing and real-time actuator control to operate as coordinated subsystems.

Motion Control & Navigation

Control & Autonomous Navigation

A mathematical model of the underwater robot was developed to describe its translational and rotational motion under the forces and moments generated by the four thrusters.

The motion-control pipeline consists of position control, attitude control, control allocation and motor control. The calculated motion commands are converted into individual thruster commands and transmitted to the embedded controller.

ROS-based control and perception were integrated with the embedded system to support visual tracking and higher-level navigation. A* and D* path-planning methods were also incorporated for autonomous navigation.
