# Portfolio design

Audience: robotics teams, researchers and recruiters evaluating Jiayi Zhao's work.

## Direction: a robotics workspace

- Ink `#12283C`: text and the engineering illustration.
- Ice `#F3F7FA`: reading surface.
- Paper `#FFFFFF`: figures and content.
- Cobalt `#245BDF`: navigation, actions and trajectories.
- Copper `#F4A261`: small mechanical joint and signal accents.
- Slate `#506579`: secondary text.

Type: Space Grotesk for titles and navigation; the system sans-serif for long reading.
Use locally hosted Space Grotesk with its OFL license. Headings are left aligned,
with short line lengths, open spacing and a restrained geometric character.

```
HOME                          CASE STUDY
name / navigation             same navigation
introduction | trajectory     title / role | project image
education / location strip    period / role / validation
four selected case studies    section navigation | overview
two repository projects                          contribution
coming soon                                      approach
about / education                                results
industry experience                              gallery
capabilities / awards                             resources
contact                       next project / contact
```

Review against the brief: avoid an all-black hacker terminal, generic dashboard
cards and decorative fake statistics. The single signature element is an original
axonometric motion-planning drawing; actual project figures carry the rest of the
visual identity. The same page generator enforces the detail-page structure.
No animation is required to read content. Keyboard focus, reduced motion, narrow
screens, image captions and semantic headings are part of the baseline.

Content: current English AI, Embedded and Robotics CVs are authoritative for the
profile. The older Industrial CV supplements mechanical work. Preserve historical
experiment limitations and distinguish personal work from team/system context.
Do not publish private CV addresses or telephone numbers.
