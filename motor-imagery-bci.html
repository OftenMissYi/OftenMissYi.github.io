Motor Imagery BCI

EEG feature extraction and visualization with wavelet-packet decomposition, developed within a team project on four-class motor-imagery decoding.

Overview

From EEG Signals to Movement Classes

This course project explored how EEG signals recorded during imagined movement can be represented and classified. The main task used BCI Competition IV 2a: left-hand, right-hand, feet and tongue imagery.

The team investigated preprocessing, time-frequency features and classification approaches, including DeepConvNet, EEGNet, FBCNet and EEG-Conformer. The project focused on offline signal analysis and classification experiments.

My Contribution

Feature Extraction & Visualization

I led the wavelet-packet feature extraction and visualization work using Python and PyWavelets, turning signal coefficients into a fixed-size representation for downstream processing. I also participated in the classification pipeline and the team's experiment analysis.

Wavelet-Packet Decomposition

The feature module applies level-5 decomposition with the Daubechies 4 wavelet. Eight selected nodes each contribute 30 coefficients, giving an output shape of (8, trials, channels, 30).

Signal Inspection

Coefficient plots make the selected node features visible and support inspection of the extraction process. The curated implementation labels nodes using their frequency ordering, since natural tree order is not frequency order.

Team Integration

The classification workflow combines MNE preprocessing, wavelet-packet features, common spatial patterns (CSP) and a PyTorch multilayer perceptron. Preprocessing and classification were developed collaboratively across the team's project sections.

Technical Approach

Classification Pipeline

  1. Prepare EEG: load a labeled GDF recording with MNE, filter at 7–35 Hz, exclude EOG channels and extract cue-aligned epochs.
  2. Extract features: decompose each trial and channel into wavelet packets and select eight nodes.
  3. Apply spatial filtering: fit four CSP components per node on the training split, then standardize the resulting 32 features.
  4. Classify: train a PyTorch MLP to distinguish the four imagery classes and record held-out metrics.

The historical script uses ten repeated random 80/20 splits within one recording. This differs from a cross-session competition benchmark. Full protocol details are documented in the repository.
